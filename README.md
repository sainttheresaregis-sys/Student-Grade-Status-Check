# ระบบตรวจสอบผลการเรียน ร และ 0

เว็บไซต์ภาษาไทยสำหรับให้นักเรียนโรงเรียนเซนต์เทเรซาค้นหารายวิชาที่มีผลการเรียน `ร` หรือ `0` ด้วยรหัสประจำตัวนักเรียน เว็บไซต์เผยแพร่ผ่าน GitHub Pages และอ่านข้อมูลจาก Google Sheet ส่วนตัวผ่าน Google Apps Script

## จุดเด่น

- ค้นหาด้วยรหัสนักเรียนแบบตรงกันทั้งหมด
- แสดงเฉพาะชื่อ ชั้น และรายวิชาที่มีสถานะ `ร` หรือ `0`
- ไม่ดาวน์โหลดรายชื่อนักเรียนทั้งโรงเรียนมายังเบราว์เซอร์
- รองรับมือถือ คีย์บอร์ด และโปรแกรมอ่านหน้าจอ
- ไม่ใช้ cookie, local storage, analytics หรือระบบติดตาม
- มีชุดทดสอบสำหรับ validation, UI controller, JSONP client และ Apps Script

## โครงสร้างระบบ

```text
นักเรียน → GitHub Pages → Google Apps Script → Google Sheet ส่วนตัว
```

GitHub Pages เก็บเฉพาะหน้าเว็บ ไม่มีข้อมูลนักเรียน ส่วน Apps Script ทำงานด้วยสิทธิ์ของบัญชีโรงเรียนและส่งกลับเฉพาะข้อมูลของรหัสที่ค้นหา

## เริ่มต้นใช้งาน

1. ทำตาม [คู่มือติดตั้งและเผยแพร่](docs/deployment.md) เพื่อสร้าง Apps Script และตั้งค่า Google Sheet
2. นำ URL ที่ลงท้ายด้วย `/exec` มาใส่ใน `config.js`
3. รัน `npm test` และ `npm run check`
4. push สาขา `main` แล้วเปิดใช้ GitHub Pages แบบ **GitHub Actions**

หากยังไม่ได้ใส่ Apps Script URL หน้าเว็บจะแสดงสถานะบริการไม่พร้อมใช้งานเมื่อค้นหา โดยไม่มีการเปิดเผยข้อมูลในชีต

## การทดสอบ

ต้องใช้ Node.js 20 ขึ้นไป และไม่ต้องติดตั้ง dependency เพิ่มเติม

```bash
npm test
npm run check
```

## ข้อจำกัดด้านความเป็นส่วนตัว

รหัสนักเรียนอย่างเดียวไม่ใช่การยืนยันตัวตนที่แข็งแรง ผู้ที่ทราบรหัสของผู้อื่นอาจดูผลของรหัสนั้นได้ ระบบนี้ลดการเปิดเผยข้อมูลแบบยกชุด แต่ไม่สามารถป้องกันการเดารหัสได้อย่างสมบูรณ์ หากต้องการความปลอดภัยสูงขึ้นควรเพิ่ม PIN หรือระบบลงชื่อเข้าใช้
