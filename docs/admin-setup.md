# ติดตั้งหน้าแอดมินเปิด–ปิดระบบ

ส่วน GitHub และ Apps Script ต้องอัปเดตทั้งคู่ การ push GitHub ไม่ได้ deploy Apps Script

1. เปิดโปรเจกต์ Apps Script เดิมจาก Google Sheet
2. แทนเนื้อหา Code.gs ด้วยไฟล์ apps-script/Code.gs ใน repository
3. เพิ่มไฟล์ HTML ชื่อ Admin และวางเนื้อหาจาก apps-script/Admin.html
4. เปิด Project Settings → Script properties เพิ่ม ADMIN_PIN เป็นรหัสที่เจ้าของระบบกำหนดในแชต เก็บเฉพาะที่นี่ ไม่ใส่รหัสใน repository
5. ตั้ง LOOKUP_ENABLED เป็น true เพื่อเริ่มโดยเปิดระบบ หรือ false เพื่อเริ่มโดยปิด
6. กด Deploy → Manage deployments → Edit เลือก New version แล้ว Deploy โดยใช้ deployment เดิม เพื่อคง URL เดิม
7. เปิดเว็บไซต์ /admin.html แล้วกดเข้าสู่หน้าแอดมิน กรอกรหัสเพื่อเปิดหรือปิด

เมื่อปิด การค้นหาผ่าน API จะคืน SYSTEM_CLOSED โดยไม่อ่านข้อมูลนักเรียน หน้าเว็บแสดงข้อความระบบยังไม่เปิดให้ตรวจสอบ เมื่อเปิดใหม่ให้ค้นหาอีกครั้ง ไม่ต้อง deploy ใหม่

รหัสจะส่งผ่าน google.script.run ของ Apps Script ไม่ผ่าน URL และไม่เก็บใน localStorage เมื่อออกจากหน้าแอดมินหรือกดออกจากระบบต้องกรอกใหม่ เมื่อกรอกรหัสผิด 5 ครั้ง ระบบจำกัดการลองรหัสของหน้าแอดมินทั้งหมดชั่วคราว 5 นาที การค้นหานักเรียนไม่ได้รับผลจากการจำกัดนี้

ตรวจหลังติดตั้ง: รหัสผิดต้องเปลี่ยนสถานะไม่ได้ ปิดแล้วค้นหาต้องไม่ส่งข้อมูลนักเรียน เปิดแล้วค้นหาได้ตามปกติ หลีกเลี่ยงการปิดระบบจริงเพื่อทดสอบในช่วงที่นักเรียนกำลังใช้งาน
